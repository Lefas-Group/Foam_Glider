What if I use a 50c instead of a 2p?

The same balance solved for a different coin, and what the substitution costs.

TipSpecified
  1. Ballast: one euro 50 cent, replacing the fitted 1p · decided by the user, 2026-08-31 · supersedes the 2p chosen the same day. Both work; this is the coin actually to hand.
Show code 
M, XCG = 0.016, 0.1640                       # as built, with the 1p at 24 mm
PENNY, PENNY_X = 3.56e-3, 0.0240
COINS = {"UK 2p": (7.12e-3, 25.9e-3), "euro 50 cent": (7.80e-3, 24.25e-3)}

x_target = neutral_point() - 0.10 * c_w
fitted = M * XCG - PENNY * PENNY_X           # moment of everything but the 1p

sol = {}
for name, (m, d) in COINS.items():
    M2 = M - PENNY + m
    x = (x_target * M2 - fitted) / m         # where this coin must sit
    t = trim(M2, x_target)
    sol[name] = dict(m=m, d=d, x=x, M=M2, t=t, stall=stall(t["V"])[0],
                     depth=float(np.interp(x, fus_x, fus_d)),
                     # fraction of MAC per millimetre the coin is misplaced:
                     # the CG moves m/M of the coin's travel, over a chord in mm
                     per_mm=(m / M2) / (c_w * 1e3))

fifty = sol["euro 50 cent"]
twop = sol["UK 2p"]

# Claims the prose makes in words rather than numbers.
assert fifty["depth"] > fifty["d"]                       # the coin fits
assert fifty["t"]["alpha"] == twop["t"]["alpha"]         # same trim angle
assert abs(fifty["t"]["LD"] - twop["t"]["LD"]) * 1.5 < 0.10   # within a few cm
assert fifty["per_mm"] * 100 < 0.25 * (fifty["stall"] - fifty["t"]["alpha"])

Answer. Centre it 61 mm from the nose — 8 mm further aft than the 2p would have gone, which still trims 2.2° below the stall.

It is very nearly a drop-in for the 2p. The reason it moves aft rather than forward is that a heavier coin needs a shorter lever to make the same moment about the target balance point. The flight is indistinguishable: both trim at the same angle and land within a few centimetres of each other. Use whichever is in your pocket.

It fits, too — the fuselage is deeper there than the coin is wide, so it tapes flat to the side with room top and bottom. Placement is forgiving: a couple of millimetres of eyeballing costs less than a quarter of the margin to the stall.

def trim(mass, x_cg, V=5.0, alpha=None, iters=60):
    """
    The angle of attack and speed at which an aircraft of this mass and balance
    flies itself: pitching moment about the CG zero, lift equal to weight.

    Takes mass and CG rather than a MassProperties, so it works for a glider
    that has been built and weighed as readily as for one that has been summed.

    AeroBuildup reports Cm about `xyz_ref`, so it is shifted to the CG first:
    Cm_cg = Cm_ref + CL * (x_cg - x_ref) / c_ref. Iterated rather than solved,
    because CL and V each determine the other and the speed moves the polar
    through Reynolds number.

    `slope` is dCm/dalpha at the crossing -- negative is a restoring moment.
    That is the honest stability test: it needs no neutral point, so it does not
    inherit the ambiguity in defining one.
    """
    a = np.linspace(-2, 14, 161) if alpha is None else alpha
    for _ in range(iters):
        p = polars(a, V=V)
        Cm_cg = np.array(p["Cm"]) + np.array(p["CL"]) * (x_cg - x_qc_w) / c_w
        i = int(np.argmin(abs(Cm_cg)))
        V = (2 * mass * 9.81 / (1.225 * S_w * float(np.array(p["CL"])[i]))) ** 0.5
    CL, CD = float(np.array(p["CL"])[i]), float(np.array(p["CD"])[i])
    return dict(alpha=a[i], V=V, CL=CL, CD=CD, LD=CL / CD,
                slope=(Cm_cg[i + 1] - Cm_cg[i - 1]) / (a[i + 1] - a[i - 1]),
                Re=p["Re_c"], sink=V / (1 + (CL / CD) ** 2) ** 0.5)

def stall(V, alpha=None):
    """
    Angle of attack where lift first stops rising, and the CL there.

    The FIRST peak, deliberately, not the global maximum. NeuralFoil's curve
    turns over near 10 degrees, dips, and then climbs again well past 20 -- deep
    post-stall behaviour the model is not meant to represent. A global argmax
    picks that second branch at some speeds and reports a stall angle of 16-24
    degrees, which is nonsense for this wing.
    """
    a = np.linspace(0, 24, 241) if alpha is None else alpha
    CL = np.array(polars(a, V=V)["CL"])
    for i in range(1, len(a) - 1):
        if CL[i] >= CL[i - 1] and CL[i] > CL[i + 1]:
            return a[i], float(CL[i])
    return a[int(np.argmax(CL))], float(CL.max())
