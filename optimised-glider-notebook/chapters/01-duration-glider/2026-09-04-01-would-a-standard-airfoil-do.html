Would a standard airfoil do?

Show code 
# Both arms at the same chord and the same Reynolds number at each aspect ratio,
# so the only difference between them is whether thickness ratio tracks chord.
ARS = np.geomspace(*DESIGN_BOUNDS["aspect_ratio"], 4)
AL = np.linspace(-2, 12, 29)
V = 6.0
naca = asb.Airfoil("naca0009").to_kulfan_airfoil()

def max_ld(af, Re):
    p = af.get_aero_from_neuralfoil(alpha=AL, Re=np.full_like(AL, Re), mach=0.0)
    return float(np.max(p["CL"] / p["CD"]))

rows = []
for ar in ARS:
    _, lay = glider(aspect_ratio=float(ar))
    c = lay["c_root"]
    Re = V * c / ATMOSPHERE.kinematic_viscosity()
    rows.append(dict(ar=float(ar), tc=FOAM_T / c, plate=max_ld(plate_section(c), Re),
                     fixed=max_ld(naca, Re)))

peak, thin, thick = max(rows, key=lambda r: r["plate"]), rows[0], rows[-1]
ratio = thick["fixed"] / thick["plate"]

assert peak is not thin               # the plate has an INTERIOR optimum
assert thin["fixed"] > thin["plate"]  # the arms disagree at the thin end too
assert ratio > 2                      # and badly where the stock is thick

2.6× optimistic at aspect ratio 12, once thickness is pinned

Answer. No. A standard section pins thickness ratio; 5 mm stock on a varying chord does not — t/c runs 4.2% to 20% across the sweep. Section lift-to-drag peaks at aspect ratio 4.2, then collapses to 2.2 where NACA 0009 still reads 5.8 (Table 1). Pinning t/c deletes the penalty that sets aspect ratio.

WarningCheap for the wrong reason

The polar loses a dimension, and the design trade goes with it.

NoteAssumed
  1. Speed 6 m/s, setting Reynolds at each chord.
  2. NACA 0009 as the stand-in standard section.
  3. Section lift-to-drag only, not the whole aircraft.
